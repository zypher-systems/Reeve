Fixes that prove they worked, and a model that sees less of your machine.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/reeve/main/install.sh | sh
```

## New

- **Verified changes.** A fix states up front how Reeve will know it worked: a unit is active, a unit logs no
  errors, a disk is under some percentage, or a read-only command shows the right thing. Reeve makes the
  changes, then runs the checks itself. If one fails, it undoes the changes, newest first, with a receipt for
  each undo. The approval card shows the goal and the checks, and whether each step can be rolled back. A
  standing order whose fix is rolled back leaves a proposal.
- **Privacy.** Before anything leaves the machine, secrets, email addresses, public IPs, and your user and
  host names are swapped for placeholders (`<secret1>`, `<host>`, …), and swapped back locally before anything
  runs or is shown.
  - A secret can only be written back into a file's content, never into a command.
  - The drafter and standing orders use `strict`, which also masks private IPs, MACs, and UUIDs.
  - Add your own words with `[privacy] terms`.
  - Local models are never masked.
  - `/privacy` shows what's masked; the header shows how many.
- **OpenRouter routing.** Requests now go only to providers that don't store or train on prompts. Zero data
  retention is a toggle in `/privacy`.

## Heads up

No-training routing is **on by default**. If every OpenRouter provider for your model collects data, requests
fail with a message saying so. Pick another model, or turn it off in `/privacy` (`t`).
