A fix for package undo on Arch.

## Update

```sh
reeve update
```

On 0.4.0 or earlier, run the installer once more instead:

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/reeve/main/install.sh | sh
```

## Fixed

- **Undoing a package that replaced another, on Arch.** That undo needs its two steps in the other
  order: pacman refuses the first try, nothing changes, and Reeve runs the second. On a machine where
  sudo prints a warning on every call (`sudo: unable to resolve host …`), Reeve took the warning for sudo
  saying no and stopped after the first try, so the undo failed every time. Reeve now goes by pacman's
  own log, in any language: if pacman started and changed nothing, the other order runs; if sudo never
  let it start, the undo stops and you aren't asked for the password again.

Nothing else changed, and nothing on Fedora.
