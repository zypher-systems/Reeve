First release of Reeve: an operator harness, an agent that runs on your computer and manages it,
with receipts for everything it does.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/reeve/main/install.sh | sh
```

or the RPM below (Fedora), or `PKGBUILD` (Arch, `reeve-bin`). Then `reeve`, `/providers`, and your API key.

## What's in it

- **A mission-control TUI:** conversation, live system panels, spend, receipts, approval cards.
- **Providers:** OpenRouter and any OpenAI-compatible endpoint, with live prices (cache reads and writes
  included), provider-reported cost, and caps per session, day, and month.
- **Tools that work anywhere on the machine:** files, shell, packages (dnf5, pacman), systemd units, the
  journal, processes.
- **Risk tiers and approvals:** T0 runs, T1 and T2 ask, and the T3 floor always needs a typed `yes`, even in YOLO.
- **Root, one action at a time:** you approve, then type your password into Reeve. It reaches sudo only.
- **Receipts:** a hash-chained audit log with undo for files (root-owned ones too), package transactions,
  and services, plus snapper pairs when snapper is set up.
- **Memory:** a machine survey, facts, runbooks with track records, and your preferences, which can be
  enforced as rules. Reflection after each session.
- **`reeved`:** a rule-based observer. Baselines, findings, desktop notifications, and an opt-in drafter
  with its own budget.
