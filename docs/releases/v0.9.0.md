**Feature.** Anthropic's own API is a connection. Pick the built-in `anthropic` connection, or
`kind = "anthropic"` on one of your own, for the chat, the drafter and standing orders, and the ledger
prices Claude at Anthropic's list prices.

## Update

```sh
reeve update
```

On 0.4.0 or earlier, run the installer once more instead:

```sh
curl -fsSL https://raw.githubusercontent.com/zypher-systems/reeve/main/install.sh | sh
```

If Reeve came from your distribution's repository, `reeve update` goes through that repository once
it carries 0.9.0; `dnf upgrade` or `apt upgrade` does the same.

## New

- **Anthropic directly.** Until now Claude came through OpenRouter. `/providers` now lists an
  `anthropic` connection beside `openrouter` and `openai`; press `s` to store the key (or export
  `ANTHROPIC_API_KEY`, or run `reeve key set anthropic`), `m` to pick a model, `⏎` to use it. The add
  form offers the kind for a second account or an endpoint of your own. The drafter and standing orders
  take it like any connection: `[observer.drafter] connection = "anthropic"`, or in `/observer`.
- **What a request carries.** Your `reasoning` setting (`low`, `medium`, `high`) is sent as adaptive
  thinking plus that effort on the models that take them; `default` sends nothing. The model's catalog
  entry says what it takes and its output ceiling, and the request follows it. Tool results travel as
  blocks, one round's in one turn, and a prompt-cache breakpoint sits on the system prompt and on the
  newest message, so each round reads the rounds before it from cache. The model's thinking is shown
  in the chat as it streams, but isn't sent back: Reeve rebuilds its system prompt every round, and
  current Claude models tie a thinking block to the exact prompt it was made under. The model
  reasons afresh each round.
- **Prices and spend.** Anthropic's model list carries no prices, so Reeve brings its published list
  prices (as of 2026-11-01), cache reads and writes included; `[pricing."claude-…"]` overrides them,
  and a model not in the table shows `$?.??` as any unknown model does. Cache reads and writes are
  counted as Reeve counts them elsewhere, so the Spend panel and `reeve spend` read the same.
- **When Claude declines.** A reply stopped by Anthropic's safety classifier is an error that names
  the category. Reeve doesn't take up Anthropic's offer to rerun the request on another model: that
  would run a model you didn't pick at a price the book didn't look up.
- **Privacy.** Masking applies as on any remote connection. The `no_training` and `zdr` switches in
  `/privacy` are OpenRouter routing and don't apply; requests go to Anthropic under its own API terms.

## Also

- Claude Haiku 5.5 charges five times its rates for a prompt over 100k tokens, which a price book
  of flat rates can't say; such a call is undercounted in the ledger.
- The new kind was exercised end to end against a stand-in Messages server and recorded fixtures, not
  against Anthropic's live API, before this release. The request and event shapes follow Anthropic's
  published reference.
- Not exercised for this release: the live container tests for pacman and apt (no package code
  changed).
